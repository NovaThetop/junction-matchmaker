# Junction Matchmaker

Matchmaking feature for the Junction platform: solo builders find teams, teams find builders, and accepting opens a chat.

- **Spec:** [MATCHMAKING.md](MATCHMAKING.md)
- **Prototype:** [index.html](index.html). Run `python3 -m http.server 8771` and open http://localhost:8771
- **Compatibility analysis:** plugs into `window.JunctionMatch` (see the spec)
